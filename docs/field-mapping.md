# Jira/Excel to GitHub Field Mapping

| Jira/Excel Field | GitHub Field | Description |
|---|---|---|
| Task ID | Issue Number | Unique task identification |
| Summary | Issue Title | Short task name |
| Description | Issue Description | Details of the task |
| Status | Project Status | Todo, In Progress, Done |
| Assignee | GitHub Assignee | Person responsible |
| Priority | Labels | Task priority |
| Comments | Issue Comments | Discussion and feedback |
| Sprint | Project Iteration | Work planning period |

## Purpose
This mapping explains how existing project tasks can be transferred from Jira or Excel into GitHub Issues and Projects.
