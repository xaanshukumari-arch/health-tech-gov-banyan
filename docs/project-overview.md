Project Overview – HealthTechGov

Introduction

HealthTechGov is a healthcare DevOps project that aims to improve software development, project management and deployment using GitHub and AWS.

Problem Statement

Problem 1: Scattered Project Information

Project tasks and information are stored across different platforms, making collaboration difficult.

Problem 2: Manual Deployment

Manual software deployment can cause human errors, delays and downtime.

Problem 3: Security and Compliance

Healthcare organisations need to protect sensitive information and maintain proper security controls.

Proposed Solution

- Use GitHub Issues and Projects for centralised task management.
- Use GitHub branching and pull requests for team collaboration.
- Use AWS DevOps services to automate deployment.
- Implement appropriate security and monitoring controls.

Expected Outcome

A more organised development workflow, automated deployment process and improved security practices.
