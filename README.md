HealthTechGov – AWS DevOps Project

Project Overview

This project aims to solve project management, manual deployment and security challenges in a healthcare organisation using GitHub and AWS DevOps services.

Problems

1. Project information is scattered across multiple tools.
2. Software deployment is manual.
3. Healthcare data requires strong security and compliance.

Proposed Solutions

- Centralise project tasks using GitHub Issues and Projects.
- Use Git and GitHub for version control.
- Automate deployment using AWS DevOps services.
- Implement security and compliance controls.

Technologies

- Git
- GitHub
- AWS
- Python
- HTML
- CI/CD

Project Structure

- src/: Source code
- docs/: Project documentation
- .github/workflows/: Automation workflows

Team Collaboration

We follow feature branches, commits, pull requests and code reviews.

Security

No passwords, secret keys or real patient data will be stored in this repository.
